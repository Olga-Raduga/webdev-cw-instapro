# Instapro

Курсовой проект — аналог социальной сети для обмена фотографиями.

## Реализованная функциональность
- Реализована общая лента постов с загрузкой данных из API.
- Реализована страница постов отдельного пользователя.
- Добавлена возможность создавать посты с описанием и фотографией.
- Добавлена загрузка фотографии в облако.
- Реализована постановка лайков.
- Реализовано снятие лайков.
- Добавлен счётчик количества лайков.
- Лайки доступны только авторизованным пользователям.
- Добавлена регистрация и авторизация пользователей.
- Реализовано сохранение авторизации после обновления страницы.
- Добавлен выход из аккаунта.
- Добавлена защита от выполнения HTML-кода в описании поста.
- Добавлено корректное отображение даты публикации на русском языке.

## Проверенные сценарии
- Неавторизованный пользователь может смотреть общую ленту.
- Неавторизованный пользователь может открывать посты конкретного пользователя.
- Зарегистрированный пользователь может войти в аккаунт.
- Новый пользователь может зарегистрироваться.
- Авторизованный пользователь может добавлять посты.
- Авторизованный пользователь может ставить и снимать лайки.
- Неавторизованный пользователь не может ставить лайки.
- После обновления страницы авторизация сохраняется.
- HTML-теги в описании отображаются как обычный текст и не выполняются.
